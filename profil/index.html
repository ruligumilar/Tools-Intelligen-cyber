TEKNOLOGI YANG DIGUNAKAN

Halaman ini dibuat dengan kombinasi teknologi frontend modern agar tampil cepat, responsif, dan mudah dipelihara. berikut teknologi utama yang dipakai serta fungsinya dalam aplikasi ini.

HTML5

Digunakan untuk struktur utama halaman, konten personel, peta, dan elemen antarmuka seperti form pencarian serta kartu data.

CSS3

Mengatur tema gelap, layout, responsivitas, animasi radar, border, shadow, dan tampilan kartu profil agar terlihat profesional.

JavaScript

Digunakan untuk menyusun data personel, filter pencarian, tombol reset, render kartu dinamis, serta interaksi navigasi di peta.

Leaflet

Library peta yang dipakai untuk menampilkan koordinat lokasi personel, marker, popup, dan zoom/fit view geospasial secara interaktif.

Font Awesome

Menambahkan ikon seperti user, map, search, download, dan tombol navigasi agar antarmuka lebih informatif dan mudah dibaca.

Google Fonts

Menggunakan tipe huruf khusus seperti Chakra Petch dan JetBrains Mono untuk kesan dashboard militer modern dan teknis.

Local Assets

Foto personel disimpan secara lokal agar lebih cepat dimuat, konsisten, dan tidak bergantung pada URL eksternal yang bisa berubah.

Responsive UI

Desain ini dibuat agar tampil dengan baik di desktop maupun ponsel, sehingga tetap nyaman digunakan dalam berbagai ukuran layar.
